# Zerodha
Zerodha Kite Clone is a full-stack web application designed to replicate the core trading experience and sleek interface of Zerodha. Built using [MongoDB, Express, React, and Node.js], it allows users to explore market watchlists, simulate buying and selling stocks, and track their holdings and positions through interactive data visualizations. (Note: Built for educational purposes only and not affiliated with Zerodha Broking Ltd.)
